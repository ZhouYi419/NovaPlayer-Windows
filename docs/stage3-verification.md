# 第三阶段：核心功能闭环与验收

日期：2026-10-25，Windows 11 x64，RTX 4060 Ti，libmpv / D3D11VA-copy。

## 实现范围

| 能力 | 行为 |
| --- | --- |
| SQLite | `videos`、`playlist_items`、`settings`；schema v2 自动迁移；后台串行队列、参数化 SQL、事务、WAL、损坏原件归档及可读记录恢复 |
| 进度保存 | 每 5 秒，以及暂停、跳转完成、倍速变化、切换、自然结束、退出；读取内核真实快照，异步入库 |
| 自动续播 | 自动 / 询问 / 始终从头；不足 5 秒、距尾不足 30 秒或已基本看完时不续播；加载完成后跳转，短暂提示并可从头播放 |
| 独立倍速 | 每视频记忆，未记录视频采用默认倍速；可全局关闭独立记忆 |
| 播放历史 | 跨重启恢复、最近优先、名称搜索、继续 / 从头、删除 / 确认清空、文件失效标记及重新定位 |
| 自动连播 | 顺序、单曲循环、列表循环、关闭连播；会话编号防止重复 EOF；有限候选与失败集合防止坏媒体无限循环；用户手动选片优先 |
| 缩略图 | 可见控件触发；最多两路后台 FFmpeg；非黑帧候选、超时杀进程、取消、任务合并、指纹校验及原子替换；JPEG 磁盘缓存复用，真实时长解析 |
| 数据保护 | 清空历史仅隐藏观看记录，保留队列和视频元数据；不删除原视频；文件变化重置旧位置、倍速和封面；退出等待最终写入与后台任务释放 |

## 验证结果

- Release 构建：0 警告、0 错误。
- xUnit：48 / 48，通过迁移、损坏备份、未来 schema 保护、路径大小写去重、锁超时及恢复、队列顺序、指纹变化和四种连播规则等测试。
- 第三阶段真实视频跨进程集成验收：31 / 31。三个独立进程依次执行 seed / resume / flow，共享专用 SQLite 档案。
- 第二阶段主界面回归：28 / 28。
- 第一阶段内核回归：16 / 16，实测 15× 约为 14.96×；真实 GPU 像素、浮层命中、缩放、全屏、最小化与资源增长检查通过。

最终便携版的第三阶段报告目录：`artifacts/stage3-0a0771de0a2a45958ab2843d18162c93/`，包含 `seed.json`、`resume.json`、`flow.json` 和三张主界面 / 历史 / 设置导出图。各阶段分别通过 7、12、12 项检查。测试视频为真实编码的 90 秒 H.264/AAC 文件，不以图片替代播放；测试脚本只改变该轮副本的时间戳、位置或内容，以验证失效和损坏媒体。

跨进程检查覆盖：真实定时保存、切换前保存、退出后恢复顺序与索引、不同视频的位置及倍速、三种续播模式、独立倍速开关、缓存命中、指纹变化后重置、删除历史跨进程保持隐藏、四种 EOF 行为、跳过失效 / 无法解码文件、清空历史保护队列与原文件。

额外使用另一连接持有写事务：保存等待期间媒体时钟仍前进；超时显示非阻塞提示；释放写锁后继续保存并清除暂时性提示。失败没有破坏后台数据库队列。

界面图通过应用自身的 WPF 视觉树与真实 GPU 帧导出，用于布局检查，不是操作系统桌面截图。原生 `WindowFromPoint` 检查另行验证浮层命中；内核回归在最小化恢复时短暂将自身测试窗口置顶，隔离其他窗口遮挡，并记录句柄诊断。正常使用不改变置顶规则。

## 复验与数据目录

```powershell
./scripts/Build.ps1 -Publish
./scripts/Verify-Stage1.ps1 -Runs 1
./scripts/Verify-Stage2.ps1
./scripts/Verify-Stage3.ps1
# 也可直接验收已发布的便携版本。
./scripts/Verify-Stage3.ps1 -PlayerPath artifacts/player/NovaPlayer.App.exe
```

请顺序执行图形验收。第三阶段默认使用第一阶段生成的样片；若传入 `-VideoPath`，建议采用 90 秒样片，以匹配验收中的 32 秒续播和 30 秒距尾规则。每次运行创建独立目录，跨进程只共享本轮的 `profile/`，与正常用户数据库隔离。

正常数据根目录为 `%LOCALAPPDATA%\NovaPlayer`：数据库 `data/player.db`，偏好 `settings/appearance.json`，缩略图 `cache/thumbnails/`，日志 `logs/`。封面在启动时按最近使用时间清理，最多 2048 张 / 256 MiB / 30 天；只清理服务自己命名的图片、元数据和过期临时文件。
