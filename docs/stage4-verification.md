# 第四阶段：高级播放体验与验收

日期：2026-10-25。环境：Windows 11 x64，RTX 4060 Ti，WPF / libmpv OpenGL Render API。

| 模块 | 实现 |
| --- | --- |
| 字幕 | 内嵌与外挂轨道、SRT / ASS / SSA、同名自动加载、语言切换、开关、20～90 标称字号、±600 秒偏移、重复外挂复用、缺失 / 损坏提示 |

字号以默认 55 为基准做缩放，ASS/SSA 保留文件排版与特效。图片字幕的字形不能按文本字号重排。本轮未改变字幕文件或原视频内容。

## 验证结果

- Release：0 警告、0 错误。
- xUnit：60 / 60。新增冲突保留、批量交换绑定、修饰键、清除 / 重置、无效手势、重复按键和无效窗口配置等边界检查。
- 最终便携版第四阶段集成验收：49 / 49，其中主流程 44 项、独立进程重启恢复 5 项。
- 第三阶段回归：31 / 31；第二阶段回归：28 / 28；第一阶段回归：16 / 16，15× 实测约 14.56×。

最终便携版报告与图像目录：`artifacts/stage4-a2e2be6d14d547778dff4c32716c6672/`。报告包括 `experience.json` 与 `experience-reopen.json`，状态中记录全部真实轨道、选中编号、字幕字号 / 偏移、会话编号及窗口几何。导出图包括 `stage4-subtitles.png`、`stage4-mini.png`、`stage4-mini-small.png`、`stage4-shortcuts.png`。

样片由现有 90 秒 H.264/AAC 文件生成：复制视频流，加入第二条 880 Hz 音频和两条不同语言的内嵌字幕，再生成同名 SRT 及独立 SRT / ASS / SSA。无字幕和坏字幕均使用本轮测试副本，不修改正常用户文件或配置。

字幕开启 / 关闭时，暂停在相同视频时间比较实际 GPU 帧，至少 11072 个像素改变；另行比较字号、时间偏移和画面比例的像素变化。验证字幕 / 音轨切换未增加播放会话编号，坏字幕只产生非阻塞提示。硬件解码改为下次打开生效，避免运行中重建解码器改变暂停帧；加载前在线程池同步应用配置，再发出打开命令。

画中画检查覆盖：默认尺寸、置顶、字幕 / 音轨 / 时间偏移 / 倍速 / 音量 / 位置保持、相同渲染器、原生窗口命中、浮层缩放手柄事件驱动真实窗口尺寸、最小尺寸下控制栏范围、关闭返回主界面、六轮往返，以及全屏和小窗互转。窗口启动时会将已失效的屏幕位置约束至可用工作区；多显示器与混合 DPI 的完整实机矩阵留给第五阶段。

快捷键检查通过实际分发器控制播放内核，覆盖旧键失效、新键生效、输入框隔离、重复抑制、特殊键别名、冲突提示、恢复默认、配置重新读取、坏配置原件保护与修改前备份。第二个独立进程验证自定义绑定、字号 / 快进间隔 / 隐藏时间、主窗口尺寸和小窗位置恢复。

界面图来自应用自身 WPF 视觉树与真实 GPU 帧导出，不是桌面截图。视觉检查修正了快捷键分组跳转的位置、最小小窗控制栏与主窗口恢复尺寸。

## 复验

```powershell
./scripts/Build.ps1 -Publish
./scripts/Verify-Stage1.ps1 -Runs 1
./scripts/Verify-Stage2.ps1
./scripts/Verify-Stage3.ps1
./scripts/Verify-Stage4.ps1 -PlayerPath artifacts/player/NovaPlayer.App.exe
```

图形脚本请顺序执行。第四阶段默认使用第一阶段生成的 90 秒样片；每轮新建独立档案，两个进程仅共享该轮 `experience-profile/`。普通配置仍在 `%LOCALAPPDATA%\NovaPlayer\settings/`。

本轮证明当前 Windows 11、显卡和所列样片上的行为；没有代替 Windows 10、多编码、多显卡、混合 DPI 及长期稳定性验证，也未生成安装程序。
