## 验证边界

- 自动验收已证明真实媒体解码、时间推进和原生窗口层级；Computer Use 启动审批超时，本次没有完成独立桌面截图和人工式鼠标点击验收。
- 高倍速压力切换中 libmpv 曾报告音画不同步，日志已记录，界面会提供非阻塞性能提示。15× 指媒体时间推进速度，不代表每秒完整解码 450 帧。
- 尚未验证 Windows 10、其他 GPU、跨显示器 DPI、全部编码与高分辨率媒体。
- 本阶段没有实现后续阶段的播放列表、持久化续播、完整设置、字幕管理或画中画。
