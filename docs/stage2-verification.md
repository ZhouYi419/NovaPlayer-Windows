# 第二阶段：主界面实现与验收

日期：2026-10-25（Asia/Shanghai）。

## 完成范围

| PRD 第二阶段项目 | 实现 |
| --- | --- |
| 顶部应用栏 | 渐变品牌标识、本地搜索、打开文件、主题菜单、自定义最小化/最大化/关闭按钮；保留原生窗口拖动和缩放 |
| 左侧导航 | 首页、播放历史、设置三项入口；选中态、悬停态和真实最近观看记录 |
| 视频播放区域 | 复用第一阶段的 GPU 宿主，保持实际比例，显示真实文件名、大小与分辨率 |
| 底部播放控制层 | 统一线性图标、圆点进度条、上/下一条、±10 秒、播放/暂停、音量、静音、倍速、全屏、信息与列表切换 |
| 右侧播放列表 | 多文件及文件夹导入、去重、选中态、实际索引、切换、拖动排序、上下移动、移除和展开/收起 |
| 底部信息区 | 播放记录、视频信息、快捷键标签；自动续播和默认倍速快捷设置；可折叠 |
| 深色主题 | 集中资源字典、统一排版/圆角/边框/图标；同时接入浅色与跟随系统主题 |
| 窗口尺寸自适应 | 1200 像素和 1050 像素阈值；窄窗口底部信息纵向排列；最小窗口主要播放控件可见 |

导航不重建播放器或渲染器，离开首页时隐藏 owned window 控制浮层，返回时重新定位并显示。快捷设置与设置页直接绑定同一个 `PreferencesService`，不会产生配置副本。

为保证可见入口有实际操作，已提供同一窗口缩放式的基础画中画、字幕显示开关与外挂字幕加载、打开文件位置、视频信息、从头播放等菜单操作。完整音轨选择、字幕样式与独立画中画渲染目标管理仍按后续阶段完善。

## 当前数据边界

- 播放历史、播放队列、独立倍速和续播位置为真实会话数据，退出后不保留。
- 只有界面偏好通过 JSON 持久化；第三阶段接入 SQLite 历史与队列持久化。
- 未读取时长的队列条目明确显示“时长待读取”，不生成假时长。
- 缩略图缓存尚未实现，封面显示统一视频图标；第三阶段替换为实际异步生成的封面。
- 不包含安装程序、全编码兼容性、跨显卡/跨系统验证或完整高级播放设置。

## 复验

```powershell
./scripts/Build.ps1 -Publish
./scripts/Verify-Stage1.ps1 -Runs 1
./scripts/Verify-Stage2.ps1
```

第二阶段脚本默认使用第一阶段生成的 90 秒样片，也可提供 `-VideoPath`。测试配置写入该轮验收目录，不改变用户平时使用的界面偏好。
